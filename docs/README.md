# 문서 지도

**축은 셋이다 — `now/` 지금 · `next/` 앞으로 · `why/` 왜.** 문서마다 축이 하나고, 축마다 시제가 하나다.
어느 축인지 모르겠는 글은 **아직 적을 자리가 없는 글**이다(DECISIONS §199).

```
docs/
  now/    MASTER.md       지금 이런 상태다 — 무엇이 있고 무엇이 도는가. 규약과 강제자의 정본(§0)
          related.md      지금 말할 수 있는 결과 — 남의 일과 견줘 어디쯤인가
          grammar.md      지금 쓰는 한국어 규약 — 합쇼체 · 조사 · 용어
  next/   PLAN.md         앞으로 할 일 · 미결정 · 범위 밖. **새 세션은 여기 §0 부터 읽는다**
          hypotheses.md   가설 대장 — 실험의 문. 검증 방법과 비용 상한이 없으면 못 들어간다
          papers.md       논문 대장 — 남이 이미 한 학습
  why/    DECISIONS.md    왜 그렇게 됐나 — 겪은 것만 적는다. **추가만 한다**
```

## 어디에 적는가

손이 멈추면 이 표를 본다. **두 곳에 적는 것이 가장 나쁘다** — 어긋나는 순간 둘 다 못 믿는다.

| 적을 것 | 자리 | 시제 |
|---|---|---|
| 무엇을 **할 것이다** · 못 한 것 · 미룬 것 | `next/PLAN.md` 의 행 | 미래 |
| 무엇을 **재 볼 것이다** — 검증 방법과 비용 상한을 들고 | `next/hypotheses.md` 의 행 | 미래 |
| 무엇이 **지금 있다** — 도구 · 셋 · 규약 · 계약 | `now/MASTER.md` 의 절 | 현재 |
| 지금 **말할 수 있는 수** — 셋 · 팔 · 구간을 들고 | `now/related.md` | 현재 |
| 무엇을 **겪었고 그래서 무엇을 고쳤나** | `why/DECISIONS.md` 의 새 절 | 과거 |
| 가설의 **판정과 근거** | `next/hypotheses.md` 의 그 행 | 과거 |

★ **같은 사실을 두 축에 적지 않는다.** PLAN 의 행이 닫히면 그 내용은 MASTER 의 절이 되고, 그 까닭은
  DECISIONS 의 절이 된다 — **옮겨 가는 것**이지 복사되는 것이 아니다.
★ **명령의 정본은 `now/MASTER.md` §0 하나다.** 최상위 `README.md` 는 문이고 목록을 안 든다 —
  두 곳에 적었더니 2026-09-29 기준 여덟 개가 한쪽에만, 다섯 개가 다른 쪽에만 있었다(DECISIONS §199).

## 번호는 자산이다

절 번호(`MASTER §7`)와 행 번호(`PLAN #3`)와 절 번호(`DECISIONS §180`)는 **지우지 않는다.**
다른 문서를 가리킬 때는 문서 이름을 앞에 적는다 — `MASTER §2` · `PLAN #3` · `DECISIONS §5`.
남의 저장소는 저장소 이름을 앞에 적는다 — `thoth MASTER §7-4`.

**`MASTER` 의 ★ 줄은 규칙이고 절 안에서 번호를 든다** — `MASTER §11-3`(DECISIONS §230).
절만 가리키면 **어느 ★ 줄을 말하는지 못 좁힌다.** 이것도 영구 식별자라 **결번이 정상**이고,
`tools/check_docs.py` 의 `check_rules` 가 유일 · 오름차순과 **가리킨 번호가 실재하는지**를 본다.
`R1`–`R7` 은 이것이 아니라 **연구 트랙**이다(`MASTER §7`) — 같은 글자를 두 뜻으로 안 쓴다.

## 강제자

문서를 손으로 지키지 않는다. `bash tools/verify.sh` 가 전부 부르고, CI 도 그것만 부른다.

| 무엇을 지키나 | 강제자 |
|---|---|
| 문체 · 절 번호 · PLAN 표 · 참조 · DECISIONS 의 꼴 · **이 지도가 실물과 맞는가** | `tools/check_docs.py` |
| 문서가 적은 경로 · 테스트가 실재하나 · 아무도 안 부르는 도구 | `tools/doc_fsck.py` |
| 실험에 드는 가설이 검증 방법과 비용 상한을 드나 | `tools/check_hypotheses.py` |
| 정규식 검사가 **거짓 초록**을 내지 않나 | `tests/test_doc_enforcers.py` 의 카나리아 |
