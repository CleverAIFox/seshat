# seshat — 실행 계획

> **앞으로 할 일만 담는 문서다.** 끝난 것은 결과를 `MASTER.md` 로, 왜 그렇게 됐는지는
> `DECISIONS.md` 로 옮기고 **여기서는 행을 지운다.** 포인터도 남기지 않는다.
>
> | 문서 | 시제 | 담는 것 |
> |---|---|---|
> | **`docs/PLAN.md`** | **미래** | **남은 일 · 범위 밖 · 위험 (이 문서)** |
> | `docs/MASTER.md` | 현재 | 규약 · 계약 · 평가 · 기계 |
> | `docs/DECISIONS.md` | 과거 | 왜 그렇게 됐나 (append-only) |
>
> 서술 규약은 MASTER §0 이고 `tools/check_docs.py` 가 강제한다.

### 이 문서의 규약

| 규칙 | 강제자 |
|---|---|
| 남은 일은 **§1 표 하나**에만 산다 | `check_plan` 「표 행이 §1 밖에 있다」 |
| §1 제목이 행 수를 든다 — `## 1. 남은 일 — N행` | `check_plan` 「제목은 N행인데」 |
| **행 번호는 영구 식별자다.** 결번이 정상이고 지운 번호는 다시 쓰지 않는다. 당기지 않고 빈자리를 채우지 않는다 | `check_plan` 「오름차순 · 겹친다」 |
| 상태는 📄 🟡 ⏳ ⚠ 넷뿐이다. 닫힌 행은 지운다 | `check_plan` 「어휘 밖」 · 「닫힘 표시」 |

| 표기 | 뜻 |
|---|---|
| 📄 | 할 일이 정해졌으나 코드 · 실측으로 확인 안 됐다 |
| 🟡 | 미결정. 판단이 필요하다 |
| ⏳ | 대기 — **여기서 못 푼다.** 막고 있는 것이 행 안에 있다 |
| ⚠ | 전제가 틀리기 쉽다. 다른 표기와 함께 쓴다 |

## 2. 지금 무엇이 막혀 있는가

**단계 ① 은 막는 것이 없다.** 서버 · 평가 · 계약 검사가 표준 라이브러리로 돌고, AWS Translate
기준선은 자격증명과 약 $2 만 있으면 된다. FLORES+ 는 Hugging Face 에서 동의 한 번이 필요할 수 있다.

**단계 ③ 은 장비가 막는다**(#19 · #20). 6GB 로는 7B 강화학습이 서지 않는다. 연말까지는 ② 의 원격
GPU 로 방법을 작게 확인한다.

## 3. 범위 밖

| 항목 | 사유 |
|---|---|
| 큰 모델을 처음부터 학습 | 데이터 · 연산 모두 사전학습 모델을 이길 수 없다. **작은 학생(#20)은 예외다** — 증류 데이터로 처음부터 학습한다 |
| 쌍 데이터 · 가중치의 저장소 커밋 | 원문이 사이트의 저작물이다. 저장소가 비공개여도 커밋하지 않는다 |
| 시험 문제를 평가셋에 옮기기 | 위와 같다 |
| GPU 상시 기동 서빙 | 유휴에도 나간다 |
| thoth 계약을 이 저장소에서 바꾸기 | 계약은 쓰는 쪽이 정한다. 바꿀 일이 있으면 thoth 에서 바꾸고 복사해 온다 |
