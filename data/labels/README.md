# 판정 — 줄마다 사람 또는 모델이 내린 뜻 판정(H-046 · DECISIONS §100 · §101)

`<셋>-<줄수>.<판정자>.jsonl` 하나가 판정자 하나의 판정이다. `<셋>-<줄수>.key.jsonl` 은 눈가림 열쇠다.

★ **원문도 출력도 여기 없다.** 줄 id · 팔 · 판정뿐이다 — 도메인셋 본문이 CC BY-SA 라서 저장소에
  들이지 않는다(카탈로그 `labels` · DECISIONS §92).
★ **판정자 하나는 자가 아니다.** 둘을 세우고 `labels.py agree` 의 카파로 자가 섰는지 본다(§101).
★ 채점표는 `/tmp` 에 있고 커밋하지 않는다. `labels.py make` 가 결정적이라 같은 seed 로 다시 만든다.
